# C++ Object-Oriented Programming Assignment

## 📌 About This Project

This repository contains my C++ Object-Oriented Programming assignment. The project focuses on implementing classes, objects, constructors, member functions, data validation, and `const` functions in practical programs.

## 📚 Programs Included

### 🔵 Circle Class

A Circle class is used to store the radius and calculate:

* Circle area
* Circle circumference
* Display circle information
* Radius validation

### ⏰ Time Class

The Time class manages:

* Hours
* Minutes
* Seconds
* Displaying time
* Adding two Time objects
* Validation of time values

### 🚗 TollBooth Class

The TollBooth program keeps track of:

* Total cars
* Paying cars
* Non-paying cars
* Total cash collected

It demonstrates how class functions can be used to manage simple toll booth records.

### 📐 Angle Class

The Angle class stores:

* Degrees
* Minutes
* Direction

It validates angle input and displays the angle in the required format.

## 🛠️ Concepts Used

* C++
* Object-Oriented Programming
* Classes and Objects
* Private and Public Members
* Constructors
* Member Functions
* `const` Member Functions
* Data Validation
* Function Parameters
* Object Passing
* Input Handling
* Conditional Statements

## 🧪 Testing & Validation

The assignment also includes testing for invalid input and boundary values, such as incorrect radius, invalid time values, and invalid angle minutes/directions.

## 🎯 Learning Objective

The main purpose of this assignment is to develop practical understanding of **Object-Oriented Programming in C++** and learn how classes and objects can be used to solve real-world programming problems.
